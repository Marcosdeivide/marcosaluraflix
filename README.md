# 🎬 clone-netflix

Projeto inspirado na interface da Netflix, desenvolvido para praticar HTML e CSS.

## 🚀 Tecnologias

* HTML5
* CSS3

## 💻 Funcionalidades

* Layout inspirado em streaming
* Organização de conteúdo em seções
* Interface visual moderna

## 📱 Responsividade

Projeto em desenvolvimento para adaptação em diferentes telas.

## 🎯 Objetivo

Praticar construção de interfaces e organização de layout no front-end.
